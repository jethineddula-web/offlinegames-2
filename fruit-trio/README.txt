Fruit Trio — HTML / CSS / JS
============================

A match-three orchard puzzle. Open index.html in any modern browser.

Files
-----
  index.html   page shell
  styles.css   layout, colors, motion
  game.js      board logic, levels, audio, save
  favicon.svg  app icon

How to play
-----------
  • Open index.html (double-click, or drag it into a browser).
  • Swap two neighboring fruits to make a line of three or more.
  • Four in a line makes a stripe. An L or T makes a burst.
    Five in a line makes a prism that clears a whole fruit.
  • Progress is stored in this browser (localStorage).

No build step, no server, no extra libraries.
If ads are blocked, the game still plays — the slots just stay empty.
