How we play games in a browser tab

Most “free games” sites send you through a maze of fake buttons before a Unity loader appears. OfflineGames is the opposite of that. The vault is a list of HTML5 cabinets we host ourselves. You tap a cover, the game opens in an overlay, and the files come from this same domain — not a mystery iframe farm.

When we say offline, we mean two practical things. First, you do not visit an app store. Second, once a game has loaded in the tab, many of them keep running even if the signal blips, because the logic lives in the page. You still need a connection to open the vault the first time. That is honest, and it is better than promising a miracle download-free console.

What we look for before a game is added

Every cartridge in the grid had to pass the same boring tests. It has to start without a login. It has to be playable with a thumb or a mouse. It has to be something we would actually reopen, not a wrapper around a 2012 flash port with the sound broken. If a build is huge — Chess 3D is the obvious example — we still ship it because the game is real, but we do not pretend it is a 200 KB toy.

We also keep a short written note for each title on the library page. That is not filler for search engines; it is how a parent can tell Chess 3D from Crazy Kingdom before a child taps the wrong cover.

Phones versus laptops

The same catalog file feeds every device. If a laptop shows a new game and a phone does not, the phone is usually holding an old copy of that file in a service worker cache. This site now asks the network for the game list instead of trusting a week-old cache. After you upload a new catalog, give the phone a refresh. You should see UNO, LUDO, Juicy Match, and whatever we add next in both places.

On a phone we also skip hover previews. Those previews are iframes. They look nice on a desktop with a mouse, and they melt a mid-range Android. Tap once to play; that is the whole gesture.

A short way to play well

  • Use the category button if you only want puzzles or racing.
  • Use search if you already know the name.
  • Random Game is a random pick when you do not want to decide.
  • Close the play overlay with the ✕ — it unloads the game so the next one is fresh.

If something is stuck, the contact page is the right door. We would rather fix a broken embed than collect a newsletter.
