Guides

These guides are written by the people who build and play the games in the vault. Each one is here because we wanted it to exist while learning a game ourselves: how to stop losing at 2048, how to read a sudoku grid without guessing, which titles suit a six-year-old, and how a browser game keeps running once the signal drops.

A word on what “offline” means here, since the term is used loosely elsewhere. There is no app store and nothing to install. Once a game has loaded in the tab it will usually keep running even if your connection drops, because the game itself lives in the page. You do still need a connection the first time you open the vault. That is the honest version, and it is the one these guides are written against.

What we look for before a game is added

Every cartridge in the grid had to pass the same boring tests. It has to start without a login. It has to be playable with a thumb or a mouse. It has to be something we would actually reopen, not a wrapper around a 2012 flash port with the sound broken. If a build is huge — Chess 3D is the obvious example — we still ship it because the game is real, but we do not pretend it is a 200 KB toy.

We also keep a short description for each title in the vault. That is not filler for search engines; it is how a parent can tell Chess 3D from Crayon Kingdom before a child taps the wrong cover.

Phones versus laptops

The same catalog file feeds every device. If a laptop shows a new game and a phone does not, the phone is usually holding an old copy of that file in a service worker cache. This site now asks the network for the game list instead of trusting a week-old cache. After you upload a new catalog, give the phone a refresh. You should see Color Clash, Ludo, Juicy Match, and whatever we add next in both places.

On a phone we also skip hover previews. Those previews are iframes. They look nice on a desktop with a mouse, and they melt a mid-range Android. Tap once to play; that is the whole gesture.

A short way to play well

  • Use the category button if you only want puzzles or racing.
  • Use search if you already know the name.
  • Random Game is a random pick when you do not want to decide.
  • Close the play overlay with the ✕ — it unloads the game so the next one is fresh.

If something is stuck, the contact page is the right door. We would rather fix a broken embed than collect a newsletter.
